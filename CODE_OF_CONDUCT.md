# Code of Conduct

## Our standard

We want this project to remain welcoming, constructive, and safe for everyone. Participate with respect, assume good faith, and focus criticism on ideas and implementation rather than people.

Unacceptable behavior includes harassment, discrimination, personal attacks, sexualized comments, threats, doxxing, and intentionally disruptive conduct.

## Enforcement

Project maintainers may edit or remove contributions and may temporarily or permanently restrict participation for behavior that violates this standard. Report concerns privately to the project maintainer rather than opening a public issue.
